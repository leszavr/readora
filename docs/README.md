## Источники правды

- API-контракты — `lib/api-spec/openapi.yaml` (orval-кодеген клиента и Zod).
- Схема БД — `lib/db/src/schema/`; применённые миграции — `lib/db/migrations/`.
- Маршруты — `artifacts/api-server/src/routes/` + `routes/index.ts`.
- Роли и доступ — `artifacts/api-server/src/middlewares/auth.ts`.

## Правила обновления

1. Задача, меняющая поведение, env, API-контракт или схему БД, обновляет релевантный документ в том же коммите.
2. Записи в [changelog.html](changelog.html) обязательны для любой завершённой задачи, меняющей код/поведение/инфраструктуру (см. AGENTS.md).
3. Документация не дублирует код построчно: фиксируются решения, инварианты и границы — то, что нельзя вывести из одного файла.
